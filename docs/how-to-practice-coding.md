# TEACH YOURESLF

1. Start on your own. 

Write the inputs, expected outputs, a few examples, and a plain-language plan.

2. Attempt the code. 

Give yourself enough time to think and experiment. Looking up syntax is allowed.

3. Ask AI for the smallest useful help. 

For example: “Give me a hint without writing the solution,” or “Help me understand this error.”

4. Review the result. 

Explain the code in your own words and test edge cases. If AI suggests a change, understand it before accepting it.

5. Practise again without the answer. 

Later, solve a similar problem from a blank file.
